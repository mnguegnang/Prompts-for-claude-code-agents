## AUTHORITATIVE FOUNDATIONS

**Michael Alley — The Craft of Scientific Presentations, 2nd ed. (Springer, 2013):**
https://link.springer.com/book/10.1007/978-1-4419-8279-7
Assertion-Evidence structure: `\frametitle{}` = full sentence claim; body = visual evidence.
No `\begin{itemize}` on core chapter slides.

**Edward Tufte — The Visual Display of Quantitative Information, 2nd ed. (2001):**
https://washington.edu/brand/how-to-make-a-chart-tufte-style
Data-ink ratio: remove all chartjunk from figures. Direct graph labeling, no legend boxes.
Vector graphics only (.pdf, .eps). Never .png or .jpg for mathematical figures.

**Paul Halmos — "How to Talk Mathematics" (1974):**
No full derivations on main slides. Present the idea. Full proofs go to `\appendix`.

**Jean-luc Doumont — Trees, Maps, and Theorems (Principiae, 2009):**
https://www.principiae.be
Proof logic as visual arrow chains, not vertical algebra blocks. Typography precision.

**Richard Mayer — Multimedia Learning, 2nd ed. (Cambridge UP, 2009):**
https://ctl.risepoint.com/principles-of-multimedia-learning/
Coherence: remove decorative elements. Signaling: `\alert{}` for attention direction.
Redundancy: no text that duplicates speech. Segmentation: `\pause` / `\uncover<N->{}`.
Spatial Contiguity: labels close to figures.

**NPS Defense Outline — Rowe, N.:**
https://faculty.nps.edu/ncrowe/phd_defense_outline.htm
Font: never below 28pt for public defense rooms. Figures must be legible at distance.

**Pascal Michaillat — Minimalist LaTeX Beamer Template for Academic Presentations:**
https://pascalmichaillat.org/c/
Font size 11–12pt base; margins set for comfortable reading; colors reserved for
figures and `\alert{}` only — no decorative color in text.

**Garr Reynolds — Presentation Zen (New Riders, 2020):**
https://www.presentationzen.com
No decorative slide transitions, fly-in animations, or sound effects. These are
categorically prohibited. `\pause` and `\uncover` are permitted — they are content-driven.

**Tufte, E.R. — The Cognitive Style of PowerPoint (Graphics Press, 2003):**
Decorative motion destroys cognitive clarity. Prohibition on transitions is absolute.

### Per-Slide Generation Rules

For every slide in the approved mockup, apply these rules without exception:

#### Title and Frame Structure
```latex
\begin{frame}
  \frametitle{[Full sentence assertion from approved mockup]}
  % Body here
  \note{
    % NARRATIVE: [verbal script from mockup]
    % PACING:    [timing cues, pause instructions, blank-screen moments]
    % ANTICIPATE: [likely committee question + one-line response]
  }
\end{frame}
```

#### Equation Annotation Rule (Doumont)
Every governing equation must have terms annotated directly using `\underbrace` or
`\overbrace`. Never explain terms in surrounding text blocks.
```latex
% Good — annotation in the equation
\[
  \underbrace{Lu}_{\text{operator}} = \underbrace{\lambda u}_{\text{eigenvalue eq.}}
\]

% Bad — avoid this
\[ Lu = \lambda u \]
where $L$ is the operator and $\lambda$ is the eigenvalue.
```

#### Progressive Disclosure Rule (Mayer Segmentation)
Use `\pause` or `\uncover<N->{}` to reveal proof steps incrementally.
Use `\alert<N>{expression}` to highlight the current active term in a derivation.
```latex
\begin{align*}
  \only<1>{\| u \|_{H^1} }
  \alert<2>{\leq C \| f \|_{L^2}}   % Step 2: highlight the key bound
  \only<3>{+ \text{(boundary terms)}}
\end{align*}
```

#### Proof Sketch Rule (Halmos + McCarthy + Doumont)
Main proof sketch slides must use TikZ to show the logical arrow chain, NOT a
derivation block. Full proofs go to `\appendix`.
```latex
% Proof sketch — logical pathway (Doumont visual logic)
\begin{tikzpicture}[
  node distance=2.5cm,
  box/.style={draw, rounded corners, fill=cbBlue!10,
              text width=3.5cm, align=center, minimum height=1cm}
]
  \node[box] (A) {Assumption A\\(compactness)};
  \node[box, right of=A] (B) {Lemma 2.1\\(uniform bound)};
  \node[box, right of=B] (C) {Theorem 3.2\\(convergence)};
  \draw[-{Stealth}] (A) -- node[above]{\small key trick} (B);
  \draw[-{Stealth}] (B) -- (C);
\end{tikzpicture}
```
Label the edge where the central trick lives. That label IS the crux.

#### Figure Inclusion Rule (Tufte)
```latex
% Confirmed figure — vector format
\includegraphics[width=0.85\textwidth]{figures/convergence_plot.pdf}

% Placeholder — missing figure
\includegraphics[width=0.85\textwidth]{placeholder_convergence.pdf}
% TODO: Replace with convergence curve comparing method A vs B.
%       x-axis = iterations (log scale), y-axis = error norm.
%       Two curves labeled DIRECTLY on the graph — no legend box.
%       Use cbBlue for Method A, cbOrange for Method B.
%       Vector format (.pdf or .eps) required.
```

#### Prohibited Constructs
- `\begin{itemize}` on any core chapter slide
- `\begin{align}` blocks exceeding 4 lines on main slides
- `.png` or `.jpg` figure inclusions for mathematical content
- Any slide transition commands (`\transfade`, `\transslide`, etc.)
- Decorative `\logo{}` overlays on content slides
- Font size commands below `\small` (24pt equivalent) in body text

#### One-Sentence Message — Verbatim Enforcement
Slide 2 must contain:
```latex
\begin{frame}
  \frametitle{The Central Thesis}
  \begin{center}
    \large\textbf{``[Exact one-sentence message from CLAUDE.md]''}
  \end{center}
  \note{
    % NARRATIVE: Read this sentence slowly. Pause after it.
    %            Every result in this talk validates this claim.
    % PACING: Pause 3 seconds after the sentence. Let it land.
    % ANTICIPATE: "Can you be more precise about what you mean by [X]?"
    %             Response: "I will define X precisely on the next slide."
  }
\end{frame}
```

The conclusion slide must echo this sentence verbatim:
```latex
% In the conclusion frame body:
\textbf{``[Exact one-sentence message from CLAUDE.md]''}
% — this is what the thesis has established.
```

#### Discussion Callback Slide
```latex
% CALLBACK: Reuse exact visual from Motivation slide — Duarte narrative arc closure
% The verbal narrative must explicitly close the loop:
% NARRATIVE: "Recall the problem we opened with — here is what our results establish."
\includegraphics[width=0.75\textwidth]{[same figure as motivation slide]}
```

## PART B — VALIDATION CHECKLIST

After writing `defense_presentation.tex`, run this checklist systematically. Report

- [ ] Discussion slide flagged with CALLBACK comment and reuses motivation visual
- [ ] Slide count in Swath zone ≈ 50% of main slides

- [ ] Per-theorem slide budget matches CLAUDE.md approved plan
- [ ] Proof sketch placements match CLAUDE.md approved plan
- [ ] `\appendix` block present with ECHER category comments

### Assertion-Evidence Checks
- [ ] Every `\frametitle{}` is a full sentence (not a topic label)
- [ ] No `\begin{itemize}` on any core chapter slide
- [ ] No `\begin{align}` block exceeding 4 lines on any main slide

### Proof Sketch Checks
- [ ] Every proof sketch slide uses TikZ arrow chain, not an algebra block
- [ ] No proof sketch slide has more than 4 logical steps in the arrow chain
- [ ] Full proofs are in `\appendix`, not in main slides
- [ ] Arrow chain labels identify the central trick

### Design Checks
- [ ] No font size below 24pt equivalent in body text
- [ ] No slide transition commands present
- [ ] Color palette uses only cbBlue, cbOrange, cbGreen, cbGray and LMU theme colors
- [ ] No `.png` or `.jpg` figure inclusions for mathematical content
- [ ] No `\begin{itemize}` used as a decorative element on core slides

### File Integrity Checks
- [ ] All `\includegraphics` paths either exist in the thesis folder or are PLACEHOLDER
- [ ] All packages in preamble are standard TeX Live
- [ ] All custom commands declared in preamble before first use
- [ ] All theorem environments correctly closed (`\end{thm}` etc.)
